### Built-in Godot 4 Isometric Support
- Godot 4.3+ has native **TileMapLayer** node with "Isometric" tile shape setting.
- Set Tile Shape to "Isometric" and configure Tile Size for automatic isometric grid.
- No external plugin required for basic isometric tilemaps.

## Art Direction Decision: 2D Pixel Art vs. 3D Low-Poly

The game needs to choose one primary art direction. Here is a comparison:

### Option A: 2D Pixel Isometric (Recommended for Solo/Small Team)
- **Pros:** Huge free asset availability, easier to mix-and-match, lighter on performance, nostalgic dungeon crawler feel, simpler Godot setup with TileMapLayer
- **Cons:** Harder to get smooth rotation/camera control, fixed perspective, mixing art styles can look inconsistent
- **Best Sources:** itch.io, CraftPix, OpenGameArt, Kenney
- **Budget Estimate:** $50-150 for a solid asset library

### Option B: 3D Low-Poly (Recommended for Polish/Scalability)
- **Pros:** Camera flexibility, consistent art style (especially Synty), easier procedural dungeon generation in 3D, modern feel
- **Cons:** More expensive upfront, requires 3D workflow knowledge, importing Unity assets to Godot requires conversion, fewer free options
- **Best Sources:** Synty Studios, Unity Asset Store, Fab.com
- **Budget Estimate:** $100-300+ for comprehensive 3D assets

### Option C: Hybrid (Voxel-to-Sprite)
- **Pros:** 3D source models rendered to 2D sprites, best of both worlds, consistent lighting/perspective
- **Cons:** Custom pipeline needed, fewer ready-made assets
- **Best Source:** monogon's isometric dungeon crawler pack

## Notes on Asset Compatibility with Godot 4.6

- **2D sprite sheets / PNG files:** Work directly in Godot with no conversion needed.
- **Unity .unitypackage files:** Cannot be directly imported. Extract the FBX/OBJ/PNG files from the package.
- **FBX/OBJ/GLTF 3D models:** Godot 4.6 supports GLTF natively. FBX support is available. OBJ works for static meshes.
- **Synty/Unity Asset Store 3D packs:** Export FBX models, re-import into Godot. Materials may need recreation with Godot's StandardMaterial3D.
- **Fab.com USD format:** Godot has experimental USD support; may need conversion to GLTF.
- **Audio (WAV/MP3/OGG):** Godot supports WAV and OGG natively. MP3 support available via import settings.
