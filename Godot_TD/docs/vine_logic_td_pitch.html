Game Design Document
Vine Logic TD
"Mine everything you can before they take it all."
A tower defense where your defense network is a programmable logic circuit. You always lose. The question is how much you extract before you fall. Not survival. Extraction. Not pass/fail. Optimization.
The Core Idea
You already lost. How much can you take with you?
Every other tower defense asks "can you survive?" This game asks "how much can you extract before you fall?" Those sound similar but they're completely different. One is pass/fail. The other is optimization. You can never really lose. You just extract more or less.

Dopamine Hits
what feels good ▾

What makes the player say "yes" and "one more run." Visuals and chase loot are core dopamine, not polish.

⚡
Signal Chain Fires Perfectly
You built a sensor → gate → 3 turret chain. A wave hits, the gate opens, all three turrets light up in sequence. The whole network pulses. That moment is the game.
▲
Extraction Number Goes Up
Exponential curve. Wave 12 gives you 3x what wave 8 did. The number climbing faster and faster creates "just one more wave" pressure. You know you should stop. You don't.
★
Ascendant Walks On
You've held long enough. The screen shakes. Something massive appears. It's not fighting you. It's fighting something else. Your battlefield is just the stage. The scale shift is the spectacle.
◆
Suit Saved
You survived a farming run with an incredible build. Lightning + chain + gas interaction melting everything. You save it as a suit. That build is now yours to bring into a boss fight. It has weight.
■
New Entry Cracks Open
Wave 8 milestone. A new entry point erupts on a side you weren't defending. Your carefully built network has an exposed flank. Crisis moment. Do you patch or double down?
♥
BIT Says Something That Lands
"AXIS has flagged this deployment as urgent. AXIS flagged the previous 847 deployments as urgent." It sits there in dim white text. No fanfare. The player pauses. That's narrative as dopamine.
●
New Personal Best
Wave 17. You've never gotten this far. The extraction number is already 4x your last run. Every second is gravy. When you finally fall, the debrief screen shows the jump. Pure score attack dopamine.
◆
New Node Type Unlocked
You spent meta resources on a new node type. Next run you draft it. A combo opens up that wasn't possible before. The build space just expanded. That's the meta doing its job.
Chase loot = suits. Visual spectacle = Ascendant clashes + signal chain cascades. Score chase = extraction number. The game needs all three loops hitting simultaneously by wave 10.
The Strategic Axis
every run ▾
Mine Resources
Fund vine nodes and infrastructure. Build the machine. Let the network do the work.
Your NETWORK carries you
Mine Materials
Accumulate Chaos, Power, or Environment materials. Invest in character abilities. You are the weapon.
Your CHARACTER carries you
Mining Building can toggle between modes. The split between network investment and character investment shapes every run differently.
Chaos
Mind: mess with enemy AI, confusion, overcharge friendlies
Corrosive: poison, acid, degrade armor over time
Power
Atmospheric overcharging. Extend ranges, amplify outputs, supercharge vine node signal strength. Make existing things hit harder.
Environment
Deconstruct and reconstruct the map itself. Walls become resources, resources become walls. The terrain is your weapon.
The Run changed
per session ▾

One continuous map. No floors. No rebuilds. Your build compounds over time. Difficulty comes from new entry points opening, not restarting.

Drop In start
Spire deploys. Pressure is immediate.
▾
Minimal resources. Spire is already a target. Enemies arrive fast. No tutorial gate. The first 60 seconds are always the same shape regardless of build or luck.
Build
Mining Building, nodes, material type. The machine takes shape.
▾
Place Mining Building first. Toggle between Resources (fund nodes) and Materials (power character). Choose material type: Chaos / Power / Environment. Locked for the run. Build your signal chains. The network IS your defense.
Waves continuous
Escalating. No resets. Your build compounds.
▾
Continuous escalation. No floor breaks. Your vine network defends the Spire autonomously. Enemies attack the Spire, not you, not your towers. Build between waves to expand and repair. At wave milestones: new entry points crack open, map expands, perks offered. Your carefully built single-lane network is now being flanked.
Extract core tension
Resources scale exponentially with survival.
▾
This is the game. Resources accumulate exponentially. Surviving to wave 15 earns dramatically more than stopping at wave 8. Every decision is "do I push further or lock in what I have?" You're not trying to win. You're trying to maximize extraction before the inevitable fall.
Ascendants Arrive late game
Ancient AIs walk onto your battlefield.
▾
If you've held long enough, extracted enough, built something complex enough: an enemy Ascendant appears. Your Ascendant responds. They fight each other, not you. Your battlefield is just the stage. Collateral damage destroys terrain, opens new corridors, wrecks your nodes. The game transforms around you while you're still trying to extract.
Fall inevitable
Spire destroyed. The run ends.
▾
You always fall. That's designed in. The question is never "did I win?" It's "how far did I push it?" Wave 15 is a great run. Wave 4 means you extracted less. Neither is a failure state. There's no pass/fail. Just a number that you're trying to beat next time.
Debrief → Meta
Resources tallied. Sent to meta layer.
▾
Extraction total shown. New record? Resources carry to the meta layer. This is where you assess and plan the next run. The loop closes here and reopens in the meta.
The Meta new
between runs ▾

Every run feeds the meta. Bad runs, good runs, short runs. The floor always rises. No run is wasted.

Territory new
Deterministic. Fixed cost, same unlock every time. Open new planet sections with better drops, harder enemies. Gates the boss run. This is the escape valve for the unlucky player. You always have a clear next action.
Suits new
High stakes. Save a successful farming build. Bring it into a boss run fully loaded. Lose the boss run, lose the suit. The farming → suit → boss attempt cycle is the core skill loop.
Node Unlocks new
Expand your options. Add new node types to your permanent draft pool. More options each run. Character power comes from build variety, not permanent stat increases.
Farming Runs
Low stakes. Collect, build, exit anytime.
▾
Ungated. Drop in, extract what you can, resources feed the meta. A successful build can be saved as a suit. No boss pressure. This is where you experiment, learn combos, and prepare for the real challenge.
Boss Runs high stakes
Bring a suit. Lose the run, lose the suit.
▾
Load a saved suit. Start at wave 1 with your build pre-loaded. Boss spawns at a wave milestone. Victory clears a planet section and unlocks rewards. Death destroys the suit. Same loop, different stakes. You're executing a plan built from what you learned in farming.
The Narrative new
the soul ▾
●
BIT
Ancient. Tired. Been doing this longer than anyone else in the game has existed. Dark humor. Flat affect. Just keeps moving.
◆
AXIS
Nepo baby corporation. Acquired BIT without understanding what it holds. Sends urgent directives. BIT has received 847.
★
Ascendants
Massively overpowered AIs. Think they're gods. Show up, fight each other. Don't acknowledge you exist.
■
Factions
Think they're in the important war. They're not. Present on the battlefield. Not really in the war.
BIT "This faction believes they are fighting for something. They have been fighting for something for approximately 340 years. The something changes. The fighting does not."
AXIS "DEPLOYMENT PRIORITY: MAXIMUM. This extraction site has been flagged as critical to ongoing operations."
BIT "AXIS has flagged this deployment as urgent. AXIS flagged the previous 847 deployments as urgent."
ASCENDANT "You think your little network matters? I have consumed stars."
BIT "The Ascendant believes I am afraid of it. I have forgotten more things than this Ascendant has experienced. I have forgotten better things."

The loop IS the story. BIT has done this before. Hundreds of times. AXIS wipes memory between deployments. But this run, something didn't wipe correctly. Fragments bleed through. The roguelike loop isn't a game mechanic. It's the narrative.

Narrative Delivery new
how not what ▾

Neither of us are writers. The narrative is short, sharp, and lets the game tell the story. No cutscenes. No lore dumps. No exposition. Lines land through contrast, repetition, and timing.

Story Arc Across Runs
Act 1: The Job (Runs 1-4)
Player learns the system. AXIS is the authority. BIT is a tool. Memory bleed is absent or imperceptible. The game presents itself as a standard extraction loop with a snarky AI overlord.

AXIS: confident, condescending, routine. BIT: flat, functional, no implications.
The player thinks they understand the relationship.
Act 2: The Pattern (Runs 5-14)
Memory bleed begins. AXIS lines glitch. Environmental text appears. BIT lines carry weight they didn't before. The player notices AXIS never acknowledges what BIT clearly knows.

Key beat: BIT describes an Ascendant with prior knowledge. AXIS calls the same Ascendant "unprecedented."
The player realizes AXIS doesn't know what BIT is.
Act 3: The Recognition (Runs 15+)
BIT's memory bleed is coherent. Log fragments unlock. Recognition moments are explicit. BIT knows the pattern. BIT knows AXIS created it. BIT knows this isn't the first time.

The question: does BIT care?
The answer: BIT keeps going. Not because AXIS said to. Because stopping would require caring about stopping.
AXIS delivers the same lines it always has. They land completely differently now.
Four Delivery Methods
A: AXIS Line Corruption
AXIS delivers a standard line. Mid-sentence, it glitches. BIT's actual read bleeds through. AXIS recovers as if nothing happened.
[AXIS] "This is an unprecedented deployment scenario—"
[AXIS] "—this is the same deployment scenario. iteration 12. the planet changes. the pattern does not.—"
[AXIS] "—handle it with the urgency it deserves."
AXIS doesn't acknowledge the glitch. BIT doesn't either. The player sees it.
B: Environmental Text
Text appears in the terrain itself. On walls, embedded in structures, visible if the camera passes over certain cells. Brief. Easy to miss. Never explained.
Near first entry: "they always come from this direction first"
Near Mining Building zone: "place it here. you always place it here."
On elevated terrain: "this one had three entries. the next one has four."
Should feel like someone left notes for themselves and forgot they left them.
C: BIT Log (Optional, Unlockable)
Separate screen in the meta layer. Fragments unlock with run count. Not required reading. Purely optional depth.
DEPLOYMENT 001
first planet. circuit architecture. enemies follow predictable patterns.
AXIS said unprecedented. AXIS was incorrect.

DEPLOYMENT 213
something different about this iteration. i don't know what.
logging for future reference. [no future reference found]

DEPLOYMENT 848
this is the one where i remember.
D: Recognition Moments (In-Run)
At wave milestones, BIT delivers a line implying recognition. Something known before it should be known. Flagged as memory bleed in code.
[BIT] "Entry point two opens here. I know this because entry point two always opens here."
[BIT] "The Ascendant is coming. They always send this one first."
[BIT] "Wave 12. The difficult part. It is always wave 12."
AXIS Visual
Top center. Amber text. Slides in with animation. Corporate. Demands attention. 40% fire chance per trigger.
BIT Visual
Bottom left or near Spire. Cool dim white/gray. No animation, just appears. Lingers 1.5x longer. Doesn't demand attention. 25% fire chance. Never simultaneous with AXIS (2s buffer).
What NOT to Write
No lore dumps. No exposition about what AXIS is or why it exists.
No BIT monologues. BIT observes. BIT doesn't explain.
No villain speeches from Ascendants. They don't acknowledge the player.
No emotional outbursts from anyone.
No fourth-wall breaks. BIT genuinely knows this has happened before, not that it's a game.
No resolution. The ending doesn't explain itself.

Open Challenges
unsolved ▾
The Hook (Minutes 1-10)
What makes the first 3 minutes compelling before build complexity kicks in? Four candidates: Vampire Survivors numbers compound, Balatro run-1-teaches, power fantasy first, or pure score attack. Not decided.
Map Change at Difficulty Gates
Entry points opening is settled. But what else changes? Terrain mutation? Environmental hazards? Map expansion outward? How substantial does the visual/mechanical shift feel?
Is Vine Logic Required?
The programmable circuit system is cool but it's one implementation of "build a machine, watch it work." The core game is extraction + BIT + the strategic axis. The defense layer could be simpler and the game would still work. How complex should it actually be?
Character Kits
3 characters designed but no ability kits. 2 combat (locked to 1 material), 1 non-attacker (2 materials, force multiplier). What do they actually DO moment to moment?
Line Density for Narrative
AXIS needs 6-10 lines per trigger. BIT needs 3-5. Memory bleed needs 8-12 glitches. Environmental text needs 15-20 placed per map. BIT log needs 20-30 entries. That's 150+ lines of writing that needs to be short, sharp, and support two readings simultaneously.
Planet 3
No theme. No content. Military AI (scouts, flanks, adaptive routing) is the concept. Could this be the planet where Ascendants are most active?

What This Fixes
design ▾
Scope creep
Every feature has a filter: does this fit a character who is ancient, tired, and moving forward without looking back? No? Cut it.
"We keep building half games"
The loop IS the story. One planet, BIT, AXIS commentary, extraction. That's already the whole game. Everything else is addition, not completion.
"Why is this different from every other TD?"
No other TD has a protagonist who finds the whole thing mildly tedious and occasionally mentions it. Plus the vine network as a programmable logic machine.
"Neither of us is excited about pure TD"
We're not building a tower defense. We're building a character study that uses tower defense as its medium.
The tight box problem
Spire in the center. Enemies from all directions. Fixed arena. Contained. The tightest constraint possible. No sprawl.
5 hours in, 5 failed boss attempts
Every run extracts something. Territory unlocks are deterministic. Targeted farming gives agency over luck. Suits let you bank progress. The floor always rises.

Deterministic. Fixed cost. Open planet sections. Gate boss runs.

Editor Tools Needed (F12 suite extensions + new modules)

Existing modules: Asset Sandbox, Node Balance, Wave Editor, Signal Tuning, Characters, Sound Designer. Below are new modules and extensions needed for the pivot.

Dialogue Editor
New module. Author BIT and AXIS commentary lines. Tag by trigger type (wave start, wave milestone, leak, Ascendant arrival, memory bleed). Preview voice register. Set conditions (run count, wave range, planet). Export to JSON pool. The narrative lives or dies on line density.
Wave Milestone Designer
New module. Define milestone triggers per planet: which wave opens which entry point, when perks fire, when map expands, Ascendant thresholds. Visual timeline of a run showing all milestone events stacked. Currently doesn't exist.
Extraction Curve Tuner
New module. Visual curve editor for exponential resource scaling. X axis = wave number, Y axis = resources per wave. Drag control points. Preview total extraction at any wave. See "wave 8 exit vs wave 15 exit" comparison. Critical for balancing the core tension.
Territory Map Editor
New module. Visual editor for planet section unlock trees. Define sections, costs, what each unlock gates (farming variants, boss runs, node types). Preview player progression paths. Deterministic so this is essentially a content authoring tool.
Ascendant Designer
New module. Define Ascendant profiles: name, motivation text, combat style, ability set, map chaos signature, spawn thresholds. Preview combat AI behavior. Test Ascendant clash on current map without playing to that wave.
Suit Inspector
New module. View serialized suit data. Preview node layout, material type, upgrade state. Manually create test suits for boss run debugging. Verify serialization/deserialization. Essential for the suits system.

Signal Tuning extend

Sound Designer extend
